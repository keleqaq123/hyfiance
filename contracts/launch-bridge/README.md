# Custos Launchpad + Bridge

This package contains the first testnet implementation of two protocol surfaces:

- `CustosLaunchpad`: permissionless fair launches plus an admin-created curated RWA lane with an onchain whitelist.
- `CustosBridge`: source-chain burn, `MessageSent` event, admin/relayer execution, destination-chain mint, and replay protection.
- `apps/relayer`: the persistent automatic off-chain message worker. See its
  README for wallet/configuration and health/message endpoints.

Run `npm run test:relayer` for isolated automatic A→B/B→A burn/mint tests.
The VM Compose configuration can rebuild this service and retains its state.

The contracts use Solidity `0.6.6` because the repository already carries a pinned local compiler. Artifacts are generated by `scripts/compile-protocol.cjs` and are intentionally ignored from Git.

## Local dual-chain run

Start two deterministic Anvil chains:

```bash
anvil --host 127.0.0.1 --port 8545 --chain-id 47805 --accounts 10 --block-time 1
anvil --host 127.0.0.1 --port 8546 --chain-id 47806 --accounts 10 --block-time 1
```

Then deploy, configure the trusted bridge pair, create demo launches, and relay one demo message:

```bash
node scripts/compile-protocol.cjs
DEPLOYER_PRIVATE_KEY=0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80 \
CHAIN_A_RPC=http://127.0.0.1:8545 CHAIN_A_ID=47805 CHAIN_A_NAME="Custos Local A" \
CHAIN_B_RPC=http://127.0.0.1:8546 CHAIN_B_ID=47806 CHAIN_B_NAME="Custos Local B" \
node scripts/deploy-protocol.cjs
node scripts/smoke-test.cjs
```

The deterministic key above is only for a local Anvil instance. Never use it on a public network.

Each deployment writes per-network records, a pair record, a frontend registry entry, and a timestamped file under `deployments/history/`.

## Public testnet deployment

The deployer key is read only from `DEPLOYER_PRIVATE_KEY`; it is never written to a file. The two bridge endpoints must be two different EVM testnets. For example, set `CHAIN_A_*` to GIWA Sepolia and `CHAIN_B_*` to the target testnet chosen by the team, then run:

```bash
DEPLOYER_PRIVATE_KEY="$DEPLOYER_PRIVATE_KEY" \
CHAIN_A_RPC="https://sepolia-rpc.giwa.io" CHAIN_A_ID=91342 CHAIN_A_NAME="GIWA Sepolia" \
CHAIN_B_RPC="$TARGET_TESTNET_RPC" CHAIN_B_ID="$TARGET_TESTNET_CHAIN_ID" CHAIN_B_NAME="$TARGET_TESTNET_NAME" \
SEED_DEMO=0 node scripts/deploy-protocol.cjs
```

Before signing, confirm the same deployer has native testnet gas on both chains and verify the target RPC/chain ID. The current workspace has no public-network deployer key, so this command must be run only after the key is injected into the shell or a secure secret manager.
