- This is the independent `keleqaq123/hyfiance` project. Do not modify the original Custos repository or its deployments.
- The public-facing name is **Hyfiance** (uppercase **HYFIANCE** where the design uses uppercase). Keep browser titles, header/footer text and application metadata consistent.
- The website mark is the H monogram with the existing white/green palette.
- The target is **Elysium Testnet**, chain ID **99801**. Native currency and gas are **HYPE**. Do not label this network GIWA or its currency ETH, and do not duplicate the word Testnet.
- Retain launchpad/project token trading, swaps/liquidity, CFI principal receipts, NFT, accounts and official bridge/faucet entry points. Independent synthetic RWA/Spot/Perpetual modules and all points/tasks remain disabled unless the user changes this scope.
- Branding edits concern displayed text. Existing contract/ABI names, deployed addresses, SDK package identifiers and internal ETH routing sentinels are compatibility details, not instructions to rename deployed contracts.
